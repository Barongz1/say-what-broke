Entry for [Say What Actually Broke](https://make.fun/bounty/u-po-pu-say-what-actually-broke-a2c153b5) on make.fun.

`main.py` writes one error line to `/output/entry.txt`:

```
Something broke, and it was the update you installed five minutes ago. Undo it, restart, and we will pretend this never happened.
```

Run it with:

```sh
python3 main.py
```
